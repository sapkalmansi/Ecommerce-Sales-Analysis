# E-Commerce Sales & Customer Insights

A beginner-friendly data analysis project using Python, Pandas, SQL and Power BI. The goal is to turn online retail transactions into clear business insights about sales trends, popular products, country performance and repeat customers.

## Dataset

Use the **UCI Online Retail** dataset: https://archive.ics.uci.edu/dataset/352/online+retail

The dataset contains transactions from a UK-based online retailer from 1 December 2010 to 9 December 2011. Download `Online Retail.xlsx` from the page above and save it to `data/raw/Online Retail.xlsx`. The raw file is intentionally not included in this repository; it is large and should be downloaded from the original source.

## Questions this project investigates

- How does revenue change by month?
- Which products contribute the most sales?
- Which countries generate the most revenue?
- How many customers place repeat orders?
- What do cancellation/return-like transactions look like?

## Tools

- Python, Pandas and NumPy for cleaning and analysis
- Matplotlib for charts
- MySQL 8 for SQL analysis
- Power BI for the interactive dashboard

## Run the Python analysis

1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Create and activate a virtual environment (optional but recommended):

   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   ```

4. Install packages:

   ```bash
   pip install -r requirements.txt
   ```

5. Download the dataset and place it at `data/raw/Online Retail.xlsx`.
6. Run:

   ```bash
   python src/analyze_sales.py
   ```

The script writes cleaned transactions and summary tables to `outputs/`. Exact results depend on the downloaded source file and cleaning rules. Review the generated tables before writing conclusions; this repository does not claim pre-computed business findings.

## Use the notebook

Open `notebooks/sales_analysis.ipynb` in Jupyter Notebook, JupyterLab or VS Code. Run the cells from top to bottom after downloading the dataset to the location above.

## MySQL analysis

1. Run `src/analyze_sales.py` first to create `outputs/sales_clean.csv`.
2. Create a MySQL database, for example `ecommerce_analysis`.
3. Run the table definition at the top of `sql/sales_analysis.sql`.
4. Import `outputs/sales_clean.csv` into the `sales_clean` table using MySQL Workbench's Table Data Import Wizard. Match the CSV columns to the table columns and verify date / decimal types.
5. Run the remaining queries in `sql/sales_analysis.sql`.

The SQL file includes monthly sales, top products, country performance, repeat-customer metrics and average order value queries.

## Power BI dashboard plan

Use **Get Data → Text/CSV** to import the generated files in `outputs/` (or import `sales_clean.csv` directly). Suggested report pages:

**1. Sales Overview**
- Total Revenue, Total Orders, Unique Customers and Average Order Value cards
- Monthly revenue line chart
- Revenue by country bar chart

**2. Product Performance**
- Top 10 products by revenue
- Top products by quantity sold
- Slicers for date and country

**3. Customer Insights**
- New vs repeat customers (define the rule in the report)
- Customer order frequency and monetary value
- Optional customer-level table for further investigation

**4. Returns / Cancellations**
- Count of invoices marked as cancelled and rows with negative quantities
- Clearly label this as a proxy for cancellation/return-like activity; do not assume every negative row is a fully refunded order.

## Data cleaning rules

The script preserves the source file, removes exact duplicate rows for the main analysis, identifies invoice IDs starting with `C` as cancellations, and separates cancellation/negative-quantity rows from positive sales. Missing Customer IDs are retained for overall sales calculations but excluded from customer-level calculations. These choices are documented so they can be explained and adjusted.
